====Array====

Basic Array Methods

| **Method**        | **Description**                                                     |
| ----------------- | ------------------------------------------------------------------- |
| `length`          | Returns the **number of elements** in an array                      |
| `toString()`      | Converts an array into a **comma-separated string**                 |
| `at()`            | Returns an element at a **specified index**                         |
| `join()`          | Joins array elements into a **string using a separator**            |
| `pop()`           | Removes the **last element** from an array                          |
| `push()`          | Adds one or more elements to the **end** of an array                |
| `shift()`         | Removes the **first element** from an array                         |
| `unshift()`       | Adds one or more elements to the **beginning** of an array          |
| `Array.isArray()` | Checks whether a value is an **array**                              |
| `delete`          | Deletes an array element, leaving an **empty slot**                 |
| `concat()`        | Joins **two or more arrays** together                               |
| `copyWithin()`    | Copies array elements to another position **within the same array** |
| `flat()`          | Converts a **nested array into a flatter array**                    |
| `slice()`         | Returns a **portion of an array** without changing the original     |
| `splice()`        | **Adds, removes, or replaces** elements in an array                 |
| `toSpliced()`     | Creates a **new array** with elements added, removed, or replaced   |


=========Array Search Methods=========
| **Method**        | **Description**                                                    |
| ----------------- | ------------------------------------------------------------------ |
| `indexOf()`       | Returns the **index of the first occurrence** of an element        |
| `lastIndexOf()`   | Returns the **index of the last occurrence** of an element         |
| `includes()`      | Checks whether an array **contains** a specific element            |
| `find()`          | Returns the **first element** that passes a condition              |
| `findIndex()`     | Returns the **index of the first element** that passes a condition |
| `findLast()`      | Returns the **last element** that passes a condition               |
| `findLastIndex()` | Returns the **index of the last element** that passes a condition  |
